# ROADMAP_DESIGNS

Home for planned pending work that is not under way: a design set aside, or a plan set aside with
its design, whether or not its work had started. Usually — not necessarily — behind a `ROADMAP.md`
item.

Work set aside here keeps its root names with the `ACTIVE_` prefix replaced by one topic no file
here already uses: `ACTIVE_DESIGN.md` becomes `<topic>_DESIGN.md`, and every other `ACTIVE_*`
file or diced tree follows. It returns under its `ACTIVE_` names once no `ACTIVE_*` file or
diced tree is at the repository root. What else changes in a set-aside plan is in
[Plan Status Form](../PROJECT_DOCS/SPEC/plan-status-form.md).

Set-aside work leaves this directory when it returns to the repository root or is abandoned —
superseded work counts as abandoned — as the `development` skill's *Plans* section states, so
this directory is routinely near-empty. This file is what keeps it present in a clone.

One rule on anything set aside here, and it holds because this directory is tracked:
**set-aside work cites only tracked paths.** A plan or design that points at scratch, at a
gitignored tree, or at a document outside the repository is a dangling reference to everyone who
clones.

Working drafts and half-formed notes are not this: they belong in scratch, which is not tracked.
