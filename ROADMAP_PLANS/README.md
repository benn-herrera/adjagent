# ROADMAP_PLANS

Home for planned pending work that is not actively under way: a design set aside before its plan
is written, or a plan with enough design done that someone could pick it up and execute it, but
which nobody is executing yet. Usually — not necessarily — behind a `ROADMAP.md` item.

Parked work leaves as the `development` skill states (its *Plans* section; superseded work counts
as abandoned), so this directory is routinely near-empty. This file is what keeps it present in a
clone.

One rule on anything parked here, and it holds because this directory is tracked: **parked work
cites only tracked paths.** A plan or design that points at scratch, at a gitignored tree, or at a
document outside the repository is a dangling reference to everyone who clones.

Working drafts and half-formed notes are not this: they belong in scratch, which is not tracked.
