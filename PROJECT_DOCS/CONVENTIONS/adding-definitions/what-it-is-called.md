### What it is called

From the output path below its deployed surface, the folder as a prefix and each
`/` and `-` read as `_`: `python_coder.py` for `agents/python-coder.md`. A group module is named
for the group, not for one member's output path; no group module is defined today.
A skill's output path is `skills/<name>/SKILL.md`, and its fixed file name is no part of the
module's name, so the module takes the skill's name alone: `kbase.py` for `skills/kbase/SKILL.md`.
The agents-file definition, which has no output path, is `harness_agents_file.py`.
